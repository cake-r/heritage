# 文博灵境 — 非物质文化遗产 AI 交互系统 · 项目立项报告

## 一、项目简介

**文博灵境** 是一套面向非物质文化遗产数字化传承场景的 AI 交互系统。系统以 4 类多模态大模型（视觉识别 Qwen-VL-Max、文本对话 DeepSeek、图像生成 通义万相、语音合成 CosyVoice）为核心引擎，围绕非遗的「识、创、修、学、游、荐」六大维度，构建了 AI 识别、文创生成、数字修复、技艺工坊、知识图谱、数字护照、个性推荐、修习之路、AI 伴游等 12+ 功能板块，为非遗传承人、文化爱好者和普通用户提供沉浸式的非遗数字交互体验。

系统采用前后端分离架构：后端 FastAPI + SQLite，前端 React 19 + TypeScript + Ant Design 6 国风主题，并完整支持 Docker 容器化部署。

## 三、系统边界

### 3.1 系统覆盖范围（In-Scope）

- **非遗品类**：19 个国家级非遗品类（剪纸、刺绣、陶瓷、漆器、木雕……）
- **历史跨度**：商周至近现代，覆盖 7 个核心历史分期、30+ 细分朝代
- **地域范围**：全国 34 个省级行政区的非遗项目
- **用户角色**：游客（浏览）+ 注册用户（创作/收藏/修习）+ 管理员（知识拓展审核）
- **AI 能力**：视觉识别、文生图、图生图、语音合成、语义检索、大模型对话
- **终端**：Web 端（React SPA），响应式适配 PC/平板

### 3.2 系统不覆盖范围（Out-of-Scope）

- 移动端原生 App（仅 Web 端）
- 社交功能（评论/私信/社区）
- 在线支付/电商交易
- 实时视频流/AR 体验
- 第三方非遗数据库对接
- 多语言国际化

## 五、技术风险与其它风险

### 5.1 技术风险

| 风险 | 影响 | 解决方案 |
|------|------|----------|
| **AI API 不稳定** — 阿里云 DashScope / DeepSeek 服务偶发超时或限流 | 识别/生成/修复功能不可用 | ① 全局 Mock 模式框架，无 API 时降级开发；② 各 AI 服务独立 try-catch，单点故障不阻塞全局；③ 修复流水线每步错误隔离，返回部分结果 |
| **TTS 阻塞 SSE 流** — CosyVoice WebSocket 合成耗时 2-5s，阻塞 chat 事件流 | 聊天回复完成后用户等待语音 | 已接受为可容忍延迟；后续可优化为异步 TTS + voice_url 事件独立推送 |
| **SQLite 并发瓶颈** — 单文件数据库，写锁竞争 | 高并发下响应变慢 | ① 当前用户量级下可行；② 已预留迁移至 PostgreSQL 路径（SQLAlchemy 抽象层） |
| **ECharts Canvas 限制** — 不支持 CSS 变量，需硬编码色值 | 主题切换时图表颜色不联动 | 所有图表组件声明硬编码色值常量，与 `tokens.css` 手动同步 |
| **ORM 跨线程问题** — SQLAlchemy 实例不可跨线程传递 | 子线程崩溃/数据丢失 | 全局采用 fire-and-forget 模式：只传主键 ID，子线程独立 SessionLocal() |
| **向量检索冷启动** — Embedding API 为每个遗产项生成 1024 维向量耗时 | 首次语义检索延迟高 | 懒加载策略：仅在首次检索时为无嵌入项生成，避免启动时全量调用 |
| **前端 401 静默跳转** — 响应拦截器在 401 时自动清除状态并跳转登录 | 用户操作中断，数据可能丢失 | 已文档化；后续可考虑刷新 Token 机制（refresh token） |

### 5.2 其它风险

| 风险 | 影响 | 解决方案 |
|------|------|----------|
| **非遗数据版权** — AI 生成的图像/文本可能涉及版权模糊 | 发布作品存在合规风险 | ① AI 生成作品标注 AI 来源；② 用户上传图片需确认版权归属；③ 知识图谱数据来源于后端种子数据 |
| **AI 内容质量** — DeepSeek 生成的非遗知识可能存在事实性偏差 | 文化传播误导 | ① 传承人角色限定专业领域 `expertise` 和 `domain_prompts`；② 知识拓展模块设审核流程（批准/驳回）；③ LLM prompt 中注入准确的非遗数据作为上下文 |
| **单点依赖** — 仅 2 个 AI 平台（阿里云+DeepSeek），任一平台变更 API 均影响功能 | 大面积功能瘫痪 | ① Mock 模式提供完全离线开发能力；② AI 服务层抽象（`base.py`），新平台接入成本低 |
| **项目交接** — 17 张表、55+ API、15 页面，文档不全则接手困难 | 后期维护成本高 | ① CLAUDE.md 已详尽记录架构/陷阱/模式；② 代码注释密度匹配周边代码风格 |
| **API Key 泄露** — .env 文件误提交至公开仓库 | 费用损失、服务被盗用 | ① .gitignore 已排除 .env；② 提供 .env.example 模板；③ Docker 部署使用 env_file 而非硬编码 |
