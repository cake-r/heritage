## 二、问题

### 2.1 技术问题

| 序号 | 问题描述 | 影响 | 解决措施 |
|------|----------|------|----------|
| 1 | **Login API 只接受 JSON Body** — 前端初期以 FormData 发送登录请求，后端无法解析 | 登录接口 400 错误 | 统一前后端为 JSON 格式，API 文档明确标注 Content-Type |
| 2 | **静态文件路径不一致** — 图片磁盘路径含 `/uploads/`，但访问 URL 不含该段 | 图片 404 | 统一规范：磁盘 `data/uploads/images/`，URL `/static/images/` |
| 3 | **Ant Design Dragger `beforeUpload` 返回 `RcFile` 无 `originFileObj`** | 上传组件类型错误 | 改用 `RcFile` 类型，移除对 `originFileObj` 的依赖 |
| 4 | **Token 过期后 401 静默跳转过于激进** — 任何 API 401 立即清空状态 | 用户操作中断 | 保留此策略但文档化，后续考虑 refresh token |
| 5 | **SQLite 写锁竞争** — 多个 fire-and-forget 线程同时写入时偶发 `database is locked` | 部分异步任务失败 | 设置 `timeout=30` 连接参数；控制并发线程数 |
